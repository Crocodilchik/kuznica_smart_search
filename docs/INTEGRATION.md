# Интеграция блока разработчика 3

## Контракт

Поисковые модели в [softline_search/contracts.py](../softline_search/contracts.py)
соответствуют полям из [распределения ролей](../project-agent-roles.md).
[Корневой contracts.py](../contracts.py) предоставляет реэкспорты для автономного запуска.
Разработчик 1 может перенести эти модели в общий контракт: дополнительные поля Product нужны
для происхождения данных и фильтрации и должны сохраняться при обмене.

```python
from contracts import HardFilters, QuerySpec, SearchParams
from softline_search.search import search

result = search(
    SearchParams(
        query_spec=QuerySpec(
            raw_query="антивирус до 100 тысяч",
            normalized_query="антивирус",
            intent="product_search",
            category="endpoint_security",
            hard_filters=HardFilters(in_stock=True, max_total_price_kopecks=10_000_000),
        ),
        mode="bm25",
        top_k=10,
    )
)
for hit in result.hits:
    print(hit.product.product_id, hit.product.title, hit.score)
```

Модуль принимает и JSON-совместимый словарь с теми же полями.
Некорректные входные параметры дают Pydantic ValidationError; техническая недоступность индекса
возвращается как `unavailable`, успешный поиск без совпадений — как `empty`.

## Работа с явным экземпляром

```python
from softline_search.search import SearchEngine

with SearchEngine("data/catalog", "data/qdrant") as engine:
    result = engine.search(params)
    product = engine.catalog.get_product("504")
    sku_matches = engine.catalog.by_sku("AL16-03SWS701-0100")
```

Один долгоживущий SearchEngine на процесс переиспользует загруженный индекс.
Local Qdrant блокирует каталог для других процессов; для многопроцессного запуска используйте сервер.
Сервис `search()` кеширует один экземпляр; `close_default_engine()` освобождает его.
Для Streamlit или LangGraph предпочтительно передать общий экземпляр явно и переиспользовать его.

В `SearchEngine` для dense/hybrid передаётся `encoder=FastEmbedEncoder(model_name)`;
нельзя использовать другую модель с тем же размером вектора.

## Категории и атрибуты

`QuerySpec.category` принимает:

- исходный ID категории, например `"2052"`;
- точное название или полный путь с разделителем ` > `;
- alias из `data/catalog/category_aliases.json`.

Фильтр распространяется на потомков. Неизвестная категория возвращает пустую выдачу с `category_unresolved`;
она не игнорируется. Alias является техническим сопоставлением по названиям дерева, а не экспертной таксономией:
разработчику 2 стоит проверить его на выбранных демонстрационных сценариях.

`attributes` содержит значимые значения исходных `param` как списки;
`attributes.description_fields` — явно размеченные пары из description, разделённые `•`.
`attributes.license_units_source` указывает, что ёмкость взята из названия.
`source_date` — дата товарного снимка. Для доказательств можно ссылаться на конкретные поля карточки.
Совместимость автоматически не подтверждается.

## Что получают остальные разработчики

1. Разработчик 1: функция поиска, диагностические поля, контракт и режимы сравнения.
2. Разработчик 2: полный справочник категорий/атрибутов, карточки и код строгих фильтров.
3. Разработчик 4: поиск по нужной категории, семейства `family_id`, описание и исходные характеристики.

Для передачи без большого XML достаточно `sample_products.jsonl`, справочников и JSON Schema.
Для запуска точного поиска нужны файлы каталога; для BM25 дополнительно требуется всё хранилище Qdrant
и его манифест. Относительный путь активного локального хранилища находится в `index.json.storage_path`;
старые сборки копировать не требуется. Простое копирование одного `index.json` индекс не переносит.
Индекс проверяет хеш исходного фида и нормализованного каталога: после изменения парсера нужна индексация заново.

## Диагностика

- `diagnostics.mode` — запрошенный режим.
- `backend` — фактически используемый механизм.
- `indexed_products` и `is_subset` — размер и полнота индекса.
- `source_date` — дата снимка, `latency_ms` — задержка конкретного вызова.
- `warnings` — ограничения данных, недоступность ветки, необходимость проверки бюджета комплекта.

Позиции с неизвестной ценой могут участвовать в обычном поиске; при жёстком бюджете исключаются.
Обогащение страны, ёмкости лицензий и совместимости требует новых проверенных данных, а не смены весов BM25.
Если страна неизвестна во всём фиде, возвращается `empty` с `country_unknown_in_catalog`:
это ограничение метаданных, а не доказательство отсутствия отечественных товаров.
`preferences` принимаются по контракту, но бизнес-переранжирование по бренду и желаемой цене пока не подключено.
