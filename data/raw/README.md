# Исходная выгрузка Softline

Положите выданный командой XML в эту папку под именем `Mindbox.yml.gz.xml`. Путь от корня репозитория — `data/raw/Mindbox.yml.gz.xml`.

Из корня репозитория выполните `docker compose run --rm --build catalog`, чтобы импортировать выгрузку и построить индекс. Для демо в режиме `test` XML не требуется.

Git игнорирует выгрузку. У каждого разработчика должна быть своя локальная копия.
